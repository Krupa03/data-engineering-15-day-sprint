# 🚀 Data Engineering 15-Day Sprint

A structured 15-day hands-on learning sprint covering the full modern Data Engineering stack.

## 🎯 Objective

Build CV-ready, interview-defensible hands-on familiarity with the complete DE/AE stack — from SQL fundamentals to Databricks, Snowflake, and production pipeline patterns.

## 🛠️ Tech Stack

**Core**
Python | SQL | PySpark | Apache Spark | Data Modeling | ETL/ELT

**Orchestration & Transformation**
Apache Airflow | dbt

**Cloud Data Platforms**
Databricks | Delta Lake | Snowflake | BigQuery | GCP

**Streaming**
Apache Kafka | Spark Structured Streaming

**Production Patterns**
SCD | CDC | Incremental Processing | Data Quality | Schema Evolution | CI/CD | Data Lineage
